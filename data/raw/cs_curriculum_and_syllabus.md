## 1. CORE COURSE DIRECTORY AND PREREQUISITE MATRIX

### CS201: Data Structures and Algorithms
- **Credits:** 4.0 (3 Lectures, 2 Lab Hours per week)
- **Prerequisite:** CS101 (Introduction to Computing & Problem Solving in C/C++) with minimum grade 'C'.
- **Course Description:** Linear data structures (arrays, linked lists, stacks, queues), non-linear data structures (binary search trees, AVL trees, B-trees, heaps), graph representations, traversal algorithms (BFS, DFS), shortest path (Dijkstra, Bellman-Ford), sorting and searching time complexity analysis.
- **Prescribed Text:** Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, Clifford Stein, *Introduction to Algorithms (CLRS)*, 4th Edition, MIT Press.

### CS202: Object-Oriented Software Design
- **Credits:** 3.0 (3 Lectures per week)
- **Prerequisite:** CS101.
- **Core Topics:** Encapsulation, inheritance, polymorphism, abstract classes, SOLID design principles, GoF design patterns (Factory, Observer, Singleton, Strategy), UML modeling.

### CS301: Database Management Systems
- **Credits:** 4.0 (3 Lectures, 2 Lab Hours per week)
- **Prerequisite:** CS201 (Data Structures and Algorithms).
- **Course Description:** Relational data model, relational algebra, SQL querying, ER diagrams, normal forms (1NF, 2NF, 3NF, BCNF), transaction management, ACID properties, concurrency control (2PL, timestamp ordering), indexing (B+ trees, hash indexes).
- **Prescribed Text:** Abraham Silberschatz, Henry F. Korth, S. Sudarshan, *Database System Concepts*, 7th Edition, McGraw-Hill.

### CS302: Operating Systems Architecture
- **Credits:** 4.0 (3 Lectures, 2 Lab Hours per week)
- **Prerequisite:** CS201 and CS204 (Computer Organization and Architecture).
- **Core Topics:** Process management, threads, CPU scheduling algorithms, process synchronization (mutexes, semaphores, monitors, Peterson's algorithm), deadlock detection and avoidance (Banker's algorithm), virtual memory management, paging, page replacement algorithms (LRU, Optimal, FIFO), file systems and disk scheduling.

### CS401: Distributed Systems and Cloud Computing
- **Credits:** 3.0 (3 Lectures per week)
- **Prerequisite:** CS302 (Operating Systems Architecture) and CS305 (Computer Networks).
- **Course Description:** Distributed consensus (Raft, Paxos), CAP theorem, remote procedure calls (gRPC), distributed storage, container orchestration with Kubernetes, map-reduce programming paradigms.

## 2. COURSE WITHDRAWAL AND PREREQUISITE WAIVER POLICY

### 2.1 Prerequisite Enforcement
- The academic registration system enforces prerequisite checks automatically.
- No student is permitted to register for a course without passing its required prerequisite courses with at least a grade 'C'.
- Under exceptional circumstances (e.g. transfer students or fast-track honours candidates), a **Prerequisite Waiver Petition** signed by the Course Instructor and Head of Department must be filed 14 days prior to registration.
